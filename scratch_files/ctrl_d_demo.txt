==================================================
        CTRL-D DEMONSTRATION - SELECT NEXT MATCH
==================================================

🎯 VSCode-Style Multiple Selection with Ctrl-D!

HOW IT WORKS:
1. Place cursor on any word
2. Press Ctrl-D to select the current word
3. Press Ctrl-D again to select the next occurrence
4. Keep pressing to add more matches
5. Type to replace all selected instances!

TEST EXAMPLE 1 - Variable Renaming:
----------------------------------------
function test() {
    var count = 0;
    count = count + 1;
    console.log(count);
    return count;
}

Try it: Place cursor on "count" and hit Ctrl-D multiple times,
then type "total" to rename all instances!

TEST EXAMPLE 2 - Multiple Words:
----------------------------------------
The quick brown fox jumps over the lazy dog.
The quick brown fox runs fast.
The quick brown fox is clever.

Place cursor on "quick" and use Ctrl-D to select all,
then change them all at once!

TEST EXAMPLE 3 - Code Refactoring:
----------------------------------------
user.name = "John";
user.age = 30;
user.email = "john@example.com";
user.active = true;
user.lastLogin = Date.now();

Select all "user" instances with Ctrl-D and rename to "customer"!

FEATURES:
✅ Selects current word on first Ctrl-D
✅ Finds next match on subsequent Ctrl-D
✅ Each selection has its own cursor
✅ All selections are highlighted
✅ Typing replaces all selections simultaneously
✅ Arrow keys clear selections
✅ Status bar shows cursor count

COMBINING WITH OTHER FEATURES:
- After selecting with Ctrl-D, you can:
  - Type to replace all
  - Use Ctrl-K to kill all selected text
  - Use Ctrl-C to copy (current line for now)
  - Click elsewhere to cancel
