Basic Shift Selection Tests
----------------------------
Shift-Right: Should select character by character
Shift-Left: Should select backward
Shift-Up: Should select to line above
Shift-Down: Should select to line below

Word Selection Tests
--------------------
Alt-Shift-Right: Should select current word
Alt-Shift-Left: Should select word backward

Line Selection Tests
--------------------
Shift-Home or Ctrl-Shift-A: Select to start of line
Shift-End or Ctrl-Shift-E: Select to end of line

Page Selection Tests
--------------------
Shift-PageUp: Select page up
Shift-PageDown: Select page down

Clear Selection Test
--------------------
ESC: Should clear selection

Navigation Between Panes
------------------------
Alt-H/J/K/L or Ctrl-Shift-Arrows: Navigate panes
Each pane should maintain its own selection state
