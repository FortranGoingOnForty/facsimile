Test File for Help Hint in Status Bar
======================================

Check the status bar at the bottom of the screen.
You should see:

Left side:  ctrl-b:fuss | filename [modified]
Center:     ctrl-/:help
Right side: Ln X, Col Y

The help hint tells users they can press ctrl-/ to see keybindings.

Try it:
- Press ctrl-/ to see the help screen
- Press any key to return to editing

Note: The README has also been updated with:
- Enhanced pane management section with better organization
- Clear note that ctrl-/ is the reliable keybinding for help
- Vim-style navigation keys (alt-h/j/k/l) documented
